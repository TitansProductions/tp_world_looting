# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Fixed an issue with the chests that are placed through the configuration file. Their positions would break easily and not being placed
in the correct position. This changed from SpawnCoords = { x, y, z, h } to { x,y,z,pitch,roll,yaw} position adjustments.

2. Improved the spawned loot random system and modified the quantity parameters from MinQuantity and MaxQuantity to Quantity = { min, max }.

## Modified Files:

- client/tp-client_main.lua
- server/tp-server_main.lua
- config.lua (check notes)
- fxmanifest.lua

## Notes

1. Modify the quantity of each random item on packages configuration option.

**BEFORE**

```lua
{ Item = "consumable_whiskey",           Label = "Whiskey",         Chance = 35,    IsWeapon = false, Weight = 0, Quantity = 1, MaxQuantity = 1},
```

**AFTER**

```lua
{ Item = "consumable_whiskey",           Label = "Whiskey",         Chance = 35,    IsWeapon = false, Weight = 0, Quantity = { Min = 1, Max = 1},
```

2. Modify from the `Config.Locations` all the `h` parameters on `SpawnCoords`.

**BEFORE**

```lua
SpawnCoords = {x = -380.413, y = 727.9819, z = 115.03, h = 191.7}, 
```

**AFTER**

```lua
-- added pitch, roll  and replace h to yaw.
SpawnCoords = {x = -380.413, y = 727.9819, z = 115.03, pitch = 0, roll = 0, yaw = 191.7}, 
```

## How to update?

- You can easily update the modified files by redownloading from the **Cfx.re Portal** and copy-paste on the mentioned directory file paths.
- If new options have been implemented to the configuration file or edited, **DO NOT** copy-paste the new configuration file, otherwise you will get the latest configuration but you will lose all the changes you have made. The proper way updating a configuration file is by finding the new configuration options or the modified ones and do it **manually**.

*Cfx.re Portal **DOES NOT** force-update your configuration file or any files, if it did, you would always lose all the configuration changes you made or would totally break the script, all files are updated or edited manually.*
